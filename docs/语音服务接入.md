# 语音服务接入

2026-11-05｜当前实现

## 配置与入口

复制根目录 `.env.example` 为 `.env.local`，将 `VITE_VOICE_SERVICE_URL` 设为用户提供的服务根地址，然后重启 Vite，或重新构建 `dist/`。`.env.local` 不提交；没有配置时使用设备合成音。前端变量仅存服务 URL，不存平台密钥。

餐桌右上角“人物＋”→“设置来宾声音”。每位来宾独立保存声音来源、平台、模型、音色、语速和音调。自定义角色也使用相同入口；示例公仔形象不决定声音。旧存档明确选择过的设备音色继续保留。服务音色库按接口动态读取，不将用户的克隆音色 ID 固定写入源码。

## 请求与播放

- `GET /api/config`：读取可用平台、模型和系统音色；只保留显示用字段。
- `GET /api/library`：读取音色库；失败时仍可用系统音色。
- `POST /api/tts`：发送当前朗读台词、所选平台／模型／音色与合成参数，使用 `X-Client-Name: Afterglow`。播放返回的内联音频，不跟随任意音频 URL。
- 不请求共享合成历史，不调用克隆／训练接口，不发送浏览器 Cookie 或平台密钥。

生成等待时显示“准备声音”，生成与播放均可停止。切换角色或声音设置会停止旧请求／旧音频，已打断响应不补播。失败时显示提示并尝试设备 TTS；设备语音也不可用时保留字幕。首次交互解锁浏览器音频；网页打开不会自动录音。

当前台词会经过服务及所选语音平台，服务可能保留记录。完整聊天历史、参考图、上传资料不随 TTS 请求发送。语音输入仍由浏览器 SpeechRecognition 处理；聊天回复仍来自本地规则，没有接入开放对话模型。

## 网络条件

本机已验证服务允许本地网页跨域调用。内网地址要求玩家能访问相应网络。当前 HTTP 本地试玩可直接调用；公共 HTTPS 网页需要 HTTPS 音色接口或服务端代理，不能直接依赖私网 HTTP 地址。代理应固定允许的上游，按部署环境配置身份验证、限流与超时；本次未搭建公共代理或公开部署。

## 验证范围

适配器单元测试覆盖配置字段过滤、模型音色绑定、默认选择、音色库失败、参数映射、取消信号和异常音频。真实接口返回了可解码 MP3；实际游戏浏览器已验证五位内置角色完成播放。详细记录在 `verification/voice-service-1105/README.md`。其他平台音色可选择，但尚未逐个实际合成验证；本次未验证麦克风人声识别、克隆或主观声音相似度。
