# 聊天触发真实画作验证 · 2026-11-09

## 实现

- 本地提供梵高 1889 年《星月夜》1280×1013 JPEG；真实二维作品复制，未生成或修改。MoMA 馆藏信息、Commons 公版来源及原始图像校验记录见 `public/artworks/SOURCES.md`。
- `paintings.ts` 匹配明确作品名，排除泛指星空、罗讷河作品及部分非作品成语；明确拒绝画面时整轮不自动展示。
- 私聊与群聊均匹配玩家文字和当前回复累积文本。语音识别完成后的文本也走同一 `send` 路径；本次浏览器操作使用打字，没有实测真人麦克风。
- 缩略图与回复并排，镜头、人物、背景不改变。点击放大不取消进行中的生成或声音，不丢弃尚在完成的对话。关闭详情返回卡片；收起卡片阻止同轮后续增量及其他群成员再次弹出。
- 模型知道界面具备这项预置图片能力，但无应用操作工具，不能宣称生成、收藏或加载已完成。收藏与换景不在此实现中。

## 浏览器实际验证

使用隔离测试存档 `painting-final-1109`，不修改用户普通存档。

1. 真实 NIA 梵高私聊回复旁出现《星月夜》缩略图，图像显示成功；桌边布局见 `starry-night-table.png`。
2. 点击后显示完整画作及馆藏／图像来源链接。图像 DOM 显示 `complete=true`、`naturalWidth=1280`、`naturalHeight=1013`；最终详情截图见 `starry-night-viewer.png`。
3. 打开详情时语音仍在播放，之后状态为“已播完 · 温暖阿虎 · 温暖男声”。从设置导出隔离存档后核对，玩家提问和对应完整角色回复均已保存。
4. Tab 可以到达 MoMA 馆藏链接，关闭详情后焦点回到缩略图按钮。
5. “先别弹出画面，只用一句话聊聊星月夜的蓝色。”获得文本回复，画作卡片数量为 0。
6. 梵高、莫奈群聊讨论《星月夜》，首位回复时画作出现；立即收起后，两位回复均完成，画作卡片仍为 0。两位已保存的群聊回复见 `group-history.png`。
