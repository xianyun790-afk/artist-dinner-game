# 角色表达实测 · 2026-11-10

用户反馈：语气机械、角色容易跑偏。使用独立存档 `persona-qa-1110` 和合成话题验收，未使用麦克风或默认存档。

- `before.json` 是修改前的 12 条真实 NIA 回复，`after.json` 是初版调整，`final.json` 是最终调整的 19 条回复。同题“你想点什么”修改前 5 位都反问；初版样本 5 位都直接答完；最终样本有 3 位答完就停、2 位仍反问。样本仅代表当次生成。
- 最终样本中，达利用“好，我安静”回应安静请求；莫奈接受“地铁”更正；同名虚构人物与画家本人分开；达利谈梵高的画时保留自己的观点。梵高给出了《星月夜》的正确馆藏，未把这一轮的观察说成当年动机。看画时问晚饭也回到晚饭话题。
- 游戏内点名达利并提到梵高，由达利回复；取消选中后聊晚饭，仍由达利接话。实际使用魅力苏菲服务音色并播完，首个声音从打字提交到播放开始约 2079 ms（首段文字 733 ms）。这是单轮结果，不含语音识别。
- `monet.mp3` 与 `dali.mp3` 通过真实音色网关和豆包 2.0 表现力模型生成，分别使用云舟和魅力苏菲。两次合成请求约 1.03／1.05 秒，见 `voice-results.json`。这验证了合成和播放链路；自然度仍需主观试听判断。
- 模型偶尔仍会追问、给出多余建议，或为角色加上未经确认的细节；规则只缩小误判范围。自动化回归覆盖了普通饮食、衣物颜色、引用对白、明确称呼、已选／上一位角色、具名画作、同名自建角色和群聊边界。

复跑：`node --experimental-strip-types verification/persona-quality-1110/probe.mjs /tmp/afterglow-dialogue.json 4894`。语音样本可用同目录的 `voice-probe.mjs` 生成。对话服务和音色服务需要在可访问的网络环境中运行。
