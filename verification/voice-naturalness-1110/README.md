## 实际限制

公开网关前端只发现整段 `/api/tts` 音频，没有证据表明当前接口支持连续音频流。本次仍是文本分句预取与顺序播放，未假称接通流式音频。

本次未采集真人麦克风、未对主观听感进行盲评，也未实测一键打断后的真人识别或免按键插话；输入逻辑以确定性测试验证片段修正、短暂停顿、自动重启、取消和迟到事件。浏览器 speechend 是估计事件，开发计时明确区分它和打字请求。播放期间仍暂停浏览器识别，避免扬声器回声误触发。

新推荐优先兼容的 expressive，已保存的手动音色保持原样；保存的 standard 不会获得 expressive 的风格指令。人物历史原声没有被复原或宣称复原。

GitHub 参考、实现范围与后续接入边界见 `docs/GitHub语音优化方案-2026-11-10.md`。没有复制第三方源码或增加新的运行依赖。
