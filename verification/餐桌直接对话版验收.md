# 餐桌直接对话版 · 2026-11-04

- 按最新参考更新为坐姿公仔、双手搭在桌边、白色背景与白色桌布，桌布上只留“光影／色彩／梦境／日常”。
- 根据后续“离得太近”反馈，默认四人比例由 1.04 缩小为 0.88，座位间距由 2.8 增至 3.25；回复全程固定镜头，不放大或靠近人物。五人席使用更小比例避免相互遮挡。
- 首屏仅一个语音入口与一个打字图标，没有侧边聊天窗、聊天历史、任务列表和关系信息。
- 浏览器实际验证：无需点人物，输入“我今天看到很好看的日落”，莫奈头顶先出现思考状态，再出现日落回复；输入梦境话题，达利直接接话。未弹出任务。
- 麦克风点击后界面进入倾听状态，随后手动暂停成功。未代替真人说话，没有声称验证真实音频识别精度。
- 语音循环实现：一次开启后识别最终文本→自动提交→暂停识别→朗读→继续识别；切后台停止，错误可改打字。字幕和话题路由也能独立使用。
- 390×844 模拟移动视口：页面宽度为 390，场景高度为 844，回复人物自动滚入视野，头顶气泡可读；场景内横向浏览保留。未做实体手机验证。
- 新坐姿素材对应五个独立 GLB，全部通过实际 skin、混合权重、五段有采样变化且彼此独立的动作检查。
- TypeScript 与生产构建通过；20 项机制测试通过。依旧有 Three.js 包体积提醒。
- 当前为本地话题规则与人设剧本，不连接云端大模型；声音由浏览器／系统提供，未克隆真人声音。
