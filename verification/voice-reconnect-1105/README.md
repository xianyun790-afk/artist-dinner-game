# 启动连接修复 · 2026-11-05

用户反馈“音色服务未连接”。本次未在当前默认浏览器页面稳定复现该提示；真实 `/api/config` 返回 200，默认存档试听梵高成功。

发现并修复：原先配置与可选音色库共用 8 秒总超时，音色库慢可能令成功读取的系统配置也失效。现在配置与音色库分别限时；音色库超时保留系统音色可用，配置失败重连一次，播放时等待当前连接任务。网络恢复／回到页面会重试失败的连接，成功后清掉过期错误。TTS 合成本身不自动重复请求。取消和旧回复丢弃仍保留。

43 项测试通过，新增慢音色库、配置超时重连、用户主动取消测试。TypeScript 与生产构建通过。实际默认页面显示已连接，梵高音色成功播放；截图 `tts-working.png`。未模拟用户原浏览器的实际网络条件；后续若仍失败需核对其当前游戏 URL 与网络环境。

同时将麦克风错误文案明确写为“语音输入／浏览器识别服务”，避免混淆角色朗读与语音输入。
