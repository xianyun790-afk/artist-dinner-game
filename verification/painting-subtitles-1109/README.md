# 满屏画作、底部台词与莫奈《睡莲》· 2026-11-09

## 本版实现

- 画面底部居中白字，仅显示台词，不显示角色名。轻阴影和底部渐暗提高复杂画面中的可读性；字幕和渐暗层不接受指针事件，不影响退出。
- useSpeech.caption 与单通道播放队列关联，在服务音频 node.start 成功或设备语音 onstart 时更新，跟随当前分句；不直接显示先到的完整模型回复。最后一句保留，新一轮或 stop 清空，取消后的迟到结果不恢复字幕。
- 没有逐字时间戳或字级高亮。音频完全不可用时字幕仍有文本回退，可能只停留在最后一段，不宣称无音频时自动分页阅读。
- 新增真实莫奈《睡莲》，芝加哥艺术博物馆藏，1906 年，馆藏编号 1933.1157。本地 JPEG 3000×2887，来源与公版／CC0证据在 public/artworks/SOURCES.md。
- 中英文作品名可触发，明确拒绝展示时不进入。玩家同一句提到两幅作品时选最后一幅，例如“星月夜看完了，看看睡莲”；普通角色评论不会把已进入的场景反复切走。
- 本地接话路由识别睡莲英文标题；NIA 提示知道两幅真实画作能力和《睡莲》的具体版本，图片仍由界面控制。

3. 字幕容器仅有 P 子元素，未显示角色名。画面与返回入口保持满屏；图片与台词均清晰可读。
