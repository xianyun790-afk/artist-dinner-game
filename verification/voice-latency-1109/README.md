# 自然语音、延迟与五位人设验收 · 2026-11-09

## 实现

- 私聊与群聊去掉原有 600 / 650 ms 固定思考等待。
- NIA 累计文本经本机 NDJSON 转发。首个完整短句或自然分句即可送 TTS；最多两段合成并发，播放保持单通道顺序。不会把最后的完整文本再读一遍。
- 一轮中已有句子进入播放队列后，如模型流失败，仅保留收到的部分并提示，不追加另一段本地回退。首句之前失败仍可回退。
- 取消会同时停止模型流、在途合成与播放；迟到的结果丢弃。群聊仍等上一位生成与播放结束后才生成下一位，避免串话与上下文错误。
- 推荐改为豆包 2.0 standard：莫奈云舟、梵高温暖阿虎、达利魅力苏菲、欧姬芙知性灿灿、林照清新女声。五位均实际合成成功。expressive 模型另实测固定角色口语指令。已有手动选择继续保留。
- 完成回复后重启识别的本地等待由 550 ms 缩短为 180 ms。
- 五位 v3 人设卡写入 server/personas.mjs，每次只加载选中的一张；同名自建角色不继承内置经历。配套可读文稿见 docs/艺术家人设-v3-自然语音.md。

## 自动验证和限制

61 项测试通过，TypeScript 与 Vite 构建通过（保留既有 bundle 体积提醒）。测试覆盖 UTF-8 文本分包、终包去重、流提前结束、队列准备并发上限、准备／播放取消、迟到结果丢弃、平台模型音色匹配，以及选中人设隔离与同名自建角色。

当前输入仍为浏览器 SpeechRecognition。没有实现豆包全双工端到端语音、语音随时插话、RTC、逐字口型；播放时暂停识别，打断使用原有按钮。未实测真人麦克风端到端延迟、声线主观偏好或长时间群聊稳定性。TTS 每段返回完整 MP3，并非音频流；分句可能增加合成请求次数。
