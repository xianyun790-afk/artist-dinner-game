# 点击退出画布才收框

日期：2026-11-09。独立测试存档 `http://127.0.0.1:4893/?slot=exit-frame-1109`。

本次按用户确认调整触发时机：**讲解结束保持画面；点击“退出画布”或按Esc，立即停止讲解并收框，再存入回忆、返回餐桌。** 此规则替代上一轮自动收框，不改变白色雕花样式。

## 实际浏览器结果

- 《星月夜》语音状态为“已播完 · 温暖阿虎 · 温暖男声”时，场景仍为`viewing`；点击退出后立即读取到`framing`。完整画框[截图](exit-shows-frame.png)。
- 《睡莲》第一句正在朗读时按Esc，立即变为`framing`，音频状态清空。退出前字幕为“花是浮在水面上的，颜色被水气晕开，没那么实。”；回忆中恰好只保存这句，没有把后面水面和倒影的未呈现讲解写入。
- 《记忆的永恒》进入后立即点击退出，尚未开讲也能收框；记录的讲解为空，界面如实显示“这次先看了画，还没有开始讲解。”。
- 三次退出各新增一条记录，总计三条。[回忆截图](exit-memories.png)。重新看已保存作品，退出同样收框且不重复收录。
