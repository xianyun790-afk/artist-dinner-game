# 直接进入《星月夜》· 2026-11-09

本版替代上一版的缩略图和资料弹窗。触发后真实画作直接成为整个游戏场景。

## 交互与状态

- `PaintingScene` 使用 fixed inset:0，图片 width/height 100%、object-fit:cover，铺满视口并按比例裁边，不拉伸。没有缩略图、标题栏、资料卡或白边；只有右上角返回按钮，Escape 也能返回。
- 餐桌保持挂载，进入时 visibility:hidden、inert、aria-hidden，隐藏的人物和管理按钮不进入键盘／辅助技术操作范围。
- 沿用原有单份 RoomInput 与语音识别状态，切换场景不重建识别器，不调用停止对话或声音。已开启的语音会话可在场景中继续；打字玩家可返回餐桌继续输入。
- 普通跟进保留画中场景；返回后抑制后续流式分句和普通跟进中角色复述作品名的重新进入，直到玩家再次明确提及作品。
- 明确拒绝画面时返回／保留餐桌，图片失败仍可使用返回按钮或 Escape。无浏览器 requestFullscreen 调用，场景覆盖游戏视口。
- 真实画作仍为本地 1280×1013 JPEG；原始来源和公版依据保留在 public/artworks/SOURCES.md。

## 浏览器实测

使用隔离存档 painting-immersive-1109，不修改用户普通存档。

1. 发送“梵高，聊聊你的星月夜，讲讲旋转的天空。”后，无需点图直接进入画中。辅助技术树仅显示画作和“返回餐桌”。
2. 当前默认 1280×720 视口中，场景和 img 的边界均为 x=0、y=0、width=1280、height=720；图片 complete=true，naturalWidth=1280，object-fit=cover。截图见 fullscreen-starry-night.png。
3. 场景内读到语音状态“正在朗读 · 温暖阿虎 · 温暖男声”，证明切场景未停止播报。Escape 可回到原有四人餐桌。
4. 再次明确提及《星月夜》可以重进。新一轮进入后立刻点击返回，餐桌仍显示“梵高正在想”；之后完整三段回复和声音均正常完成，没有被取消或再次进入。最终状态“已播完 · 温暖阿虎 · 温暖男声”，画中返回按钮数量 0，截图见 after-return.png。
